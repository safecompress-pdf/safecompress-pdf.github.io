Privacy Policy — SafeCompress PDF

Last updated: 2026-08-28

Overview

SafeCompress PDF compresses PDFs locally in your browser. Files are processed on your device and never uploaded.

What We Collect

Nothing. No personal data, file content, or analytics collected.

How Processing Works

  1. File read into browser memory
  2. Pages rendered locally with bundled pdf.js
  3. New PDF created with pdf-lib
  4. Download offered — no file leaves browser

No network requests during compression (verified: manifest permissions [] and no fetch/XHR in source, checked 2026-08-28).

Permissions

No Chrome permissions, no host permissions — verifiable in manifest.json: "permissions": [], "host_permissions": []. Cannot access history, tabs, websites, cookies.

Local Storage

Only localStorage safecompress_log (filename, sizes) and theme preference, on-device only, cleared on uninstall, exportable TXT/CSV, clearable via button.

Libraries

Bundled locally: pdf.js, pdf-lib — loaded from extension package, not external servers. Exact versions require verification.

Offline

Works offline after install — libraries bundled, but real-browser offline test pending; claim qualified as “No server upload code found on 2026-08-28”.

Limitations

Do not claim 100% secure/private. Security depends on device/browser.
