Privacy Policy — SafeCompress PDF

Last updated: 2026-09-17

Overview

The SafeCompress PDF Chrome extension compresses PDFs locally on your device without uploading them. This website is separate from the extension and uses Yandex Metrika analytics, as described below. The local-processing statements in the extension sections do not describe website analytics.

Extension Data and Tracking

The extension processes PDF content locally and keeps an on-device history log. No analytics or tracking has been added to the extension by this website integration; the Yandex Metrika counter is included only on website pages.

How Extension Processing Works

  1. File read into browser memory
  2. Pages rendered locally with bundled pdf.js
  3. New PDF created with pdf-lib
  4. Download offered — no file leaves browser

The extension source review dated 2026-08-28 reported no network requests during compression (manifest permissions [] and no fetch/XHR in source). This historical finding concerns the extension, not requests made by this website.

Extension Permissions

The extension's previously reviewed manifest.json declares "permissions": [] and "host_permissions": []: no Chrome or host permissions to access history, tabs, websites or browser cookies. This does not restrict this website's analytics script.

Extension Local Storage

The extension stores localStorage safecompress_log (filename, sizes) and theme preference on-device only. The log is cleared on uninstall, exportable as TXT/CSV and clearable via a button.

Extension Libraries

pdf.js and pdf-lib are bundled locally and loaded from the extension package, not external servers. Exact versions require verification.

Extension Offline Use

The extension's libraries are bundled for offline use after installation, but a real-browser offline test is pending. The historical finding is limited to “No server upload code found on 2026-08-28”.

Website Analytics — Yandex Metrika

This website uses Yandex Metrika counter 112760352, a third-party analytics service provided by Yandex. The website loads its script from mc.yandex.ru; this is not local-only data processing.

The counter enables Webvisor (session interaction recording and replay), click maps, link tracking and accurate bounce metrics to understand website usage. The page URL and referrer are sent to Yandex along with website usage and interaction data. Yandex Metrika may use cookies and browser identifiers.

These analytics concern visits to this website, not PDF processing inside the extension. If JavaScript is disabled, the supplied counter includes an image request to Yandex. Browser privacy settings or ad blockers may block analytics requests.

The current integration loads without a consent gate; this policy does not mean that consent has been obtained. Before public deployment, the site owner must determine the applicable consent requirements and implement any required consent gate or disable the relevant tracking.

Limitations

Neither the extension nor the website is guaranteed to be 100% secure or private. Security also depends on your device and browser.
